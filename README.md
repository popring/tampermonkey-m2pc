# tampermonkey-m2pc

此脚本为了兼容移动端分享的链接在电脑端无法自动转换为电脑端网页链接。

## 当前支持的网站

- 虎嗅网 (`m.huxiu.com` → `www.huxiu.com`)
- 澎湃新闻 (`m.thepaper.cn` → `www.thepaper.cn`)
- Three.js 文档 (英文文档 → 中文文档)
- 京东商品页 (`item.m.jd.com` → `item.jd.com`)

## 需要支持新网站？

如果你发现某个网站在电脑上访问移动端链接时不会自动跳转到 PC 端，欢迎提 [Issue](https://github.com/popring/tampermonkey-m2pc/issues) 或提交 PR！

# tampermonkey-m2pc

This script automatically converts mobile links to desktop versions when accessed from a computer.

## Currently Supported Sites

- Huxiu (`m.huxiu.com` → `www.huxiu.com`)
- The Paper (`m.thepaper.cn` → `www.thepaper.cn`)
- Three.js Docs (English docs → Chinese docs)
- JD.com Product Pages (`item.m.jd.com` → `item.jd.com`)

## Need Support for a New Site?

If you find a website that doesn't automatically redirect from mobile to desktop when accessed from a computer, please submit an [Issue](https://github.com/popring/tampermonkey-m2pc/issues) or a PR!

Tampermonkey plugin installation address: https://greasyfork.org/zh-CN/scripts/510561-%E7%A7%BB%E5%8A%A8%E7%AB%AF%E9%93%BE%E6%8E%A5%E8%B7%B3%E7%94%B5%E8%84%91%E7%AB%AF
